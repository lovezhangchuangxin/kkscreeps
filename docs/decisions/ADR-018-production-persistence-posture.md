# ADR-018：生产持久化姿态——周期检查点权威，输入日志为显式审计件

- 日期：2026-10-10
- 状态：接受；技术基座（输入日志 v2 摘要化/流式化、检查点+截断+重执行的恢复语义）随日志 v2 批交付，服务侧接线（周期保存调度与配置面）随 embed 常驻服务形态（G27.b/G28 线）落地。

部署基准（用户拍板，2026-10-10 定稿、同日修订）：2GB 内存的轻量云服务器须跑得动（官方私服同基准可运行），容量目标为 9 个区块大小的地图（每区块 9×9=81 房）上 ≥50 名玩家、平均每玩家 6 房、总占用 300 房（修订自 ≥100 玩家×3 房，总房数不变、玩家数减半：每玩家 isolate/线程的结构足迹随之减半，JSON 通道逐玩家地形嵌入 churn 随玩家数下降，KKPV 共享块摊销随总房数不变）；性能高、内存占用小、不过度设计。

2026-10-10 用户再次修订成功条件：2GB 作为轻量部署的参考目标，不再是性能成功的硬门槛；近期只验收 50 玩家×6 满功能成熟房共同负载，相比 xxscreeps 更快且内存更低即满足本批目标。玩法未完全实现时允许有限结果差异，报告必须量化披露；现有兼容性棘轮仍独立保持。上段与下文的 2GB 达标判定保留为当时容量研究结论，不阻塞相对性能路线。

输入日志（G25.a）为逐位回放验证（开发期确定性验收的方法论承重件）而设计，v1 每拍全量携带玩家 Memory，体积随拍数无界增长（实测 30KB/拍、86400 拍单份 2.6GB），重启/恢复路径整读解析的峰值内存超出轻量实例承受范围。官方引擎与 xxscreeps 的对照盘点（2026-10-10，证据在当批台账）表明：两者都不为重放保留无界历史——官方每拍把状态增量写进 storage 进程（最新值、有界），xxscreeps 房间整体 blob 双缓冲+脏标记、约 2 分钟批量落盘；官方崩溃恢复=gameTime 不变整拍重跑、xxscreeps=回滚到上次落盘。

决策：**生产（常驻服务）默认不启用输入日志**。持久化权威是周期检查点（世界+玩家 Memory 的一致对，原子发布，间隔可配）；崩溃恢复=回滚到最近检查点，间隔内的拍丢弃后由后续轮次自然重跑（官方模型；kk 候选提交的原子性保证无半拍状态）。RPO=检查点间隔，与官方/xxscreeps 同级取舍，作为配置项向部署者显式声明，不承诺零丢失。输入日志是显式开启的开发/审计件：开启时按 v2 协议（Memory 摘要、流式扫描、恢复时游标截断+重执行）运行，长窗体积与读取内存有界于窗口与后缀。生产日志保留策略（若部署者开启审计）由检查点锚定的轮转在服务切片定义。

目标形态细化（2026-10-10 用户拍板）：**需要近期历史的能力（回放/回收/审计类）走 Mod 支持，不做进核心服务**——核心只有「检查点最新值 + 回滚重跑」，Mod 可选择保存最近一段有界窗口的数据（基于输入日志机制加保留策略，或 Mod 自有的记录域），窗口外数据不承诺。核心不为历史类能力保留无界状态；这是「不过度设计」原则在持久化面的直接应用。

不选择「生产也带日志换 RPO=1」：v1 的 RPO=1 依赖日志携带 Memory 全值，这正是无界体积的来源；摘要化后重放无法恢复 Memory，继续走重放会产生「世界到日志尾、Memory 停在检查点」的不一致对（日志 v2 批实测复现并以此改为重执行模型）。也不选择最新值 Memory 旁路文件（官方 kv 式）：在「回滚到检查点」的恢复语义下冗余——检查点已含 Memory 一致对；该机制只在需要 Memory 独立于世界的更细 RPO 时再评估，当前无此需求，按不过度设计原则不建。

后续约束：embed 常驻服务的默认配置不得启用输入日志；任何把日志设为生产默认的变更须推翻本 ADR 并重新论证容量。满员容量路径的剩余风险是 V8 isolate 足迹（与持久化无关），已由实测切片（D，2026-10-10，[capacity-isolate-probe](../../compat/reports/capacity-isolate-probe/summary.json)）在服务线动工前完成测量：每玩家边际常驻 ≈8.5MiB（macOS 口径，Linux 须复测）；JSON 通道因全服地形逐玩家嵌入而执行期增长超线性，KKPV 在 100 玩家下全面反超（project -27%/run -45%/RSS 峰值 -36%）——生产默认通道建议 KKPV。修订口径（50 玩家×6 房，同日）已按 p50x6 双通道实测：KKPV 峰值 1004MiB、JSON 峰值 1454MiB，**均低于 2GiB**（macOS 分配器口径、100 拍窗口未稳态，GC 稳态长窗与 Linux 2GB 服务形态复测仍是最终验收）。三项工程路径相应降级：生产默认 KKPV 仍推荐（成本面全面占优）；JSON 通道地形嵌入改造降为优化项；isolate 生命周期管理/LRU 驱逐从达标必要条件降为保险与扩展项。
