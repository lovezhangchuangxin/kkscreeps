# ADR-017：独立线程的异步后台服务域

- 日期：2026-10-09
- 状态：接受，G27.a 首片已交付；现行机制与验收见[后台服务](../architecture/background-services.md)。

玩法 realm 同步执行候选，不能运行外部 I/O 或等待后台 Promise。storage/provider 和 outbox 需要独立异步消费者；现有 embed 不是后台宿主。

首片把可信 services 入口装到独立线程的 V8 realm。模块字节与依赖顺序来自同一包快照和内容选择；入口同步注册，start/request/stop 可异步返回。有限队列在宿主侧拒绝过载，不把 V8 跨线程移动，也不在玩法执行线程 block_on 后台操作。

服务只能读取宿主传入的脱离世界的快照，调用明确授予该包的命名只读探针。探针异步实现由 Rust 注入并限制输入/输出与调用数量；没有 fetch、任意文件访问、世界写入或玩家上传代码的可信装载。CPU、墙钟和内存复用 kk-vm 预算；故障后销毁域与剩余请求，重新启动必须重新注册和 start。多包共享可信后台域，不提供包间恶意代码隔离。

start 按依赖序，stop 反序；服务调用串行，先完成当前回调再处理下一项。回调结束时不能遗留正在运行的探针。后台 JS 全局与队列仅为进程态，冷启动清空；本片不把它们保存为游戏写入域，也不承诺崩溃后重放。未来需要耐久输入或输出时由 G27.b 的原子发布/消费游标/outbox 接管，不用后台变量冒充耐久状态。

暂不选择把异步循环塞入玩法 realm：等待会阻塞整轮候选，且使外部响应影响重放。也暂不引入进程服务总线：首片只验证生命周期和有限探针，进程隔离可在有实际故障/规模证据后追加。
