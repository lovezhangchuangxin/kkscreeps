| R05 | 缺失父目录时，链接祖先绕过包内输出保护 | 逐组件解析已有祖先，同时保护实体和原子替换的目录项；拒绝后无新目录 |

| R08 | trace 新增的 mod_id 使旧自动停用记录无法解码 | 从 trigger 的结构化绑定补齐缺失来源；来源矛盾拒绝；完整检查点恢复回归 |
| R09 | sim run 失败报告可覆盖 Mod 输入 | 在场景装载、注册和失败报告之前保护场景声明的源码目录，复用同一路径守卫 |
| R10 | 带停用掩码的恢复装配可留下一条 tick=0 的伪运行 trace | 替代分片装配期间关闭 trace，恢复完成从空缓冲按已恢复时间续跑 |

相关质量改进：init 原子占用目录并拒绝 builtin；模板复制指引提醒同步全局名，控制台命令引用路径；声明原子替换避免截断源码硬链接；test 私有中间报告目录自动清理，无法读取结果时不计通过；清除 trace 测试的双引用 clone 警告。typegen 描述符支持门不替代引擎执行入口校验，已修正文档中过强的承诺。固定场景不保证任意玩家脚本确定性，trace 文档与本地模拟的 Date/Math.random/CPU 约束统一。
