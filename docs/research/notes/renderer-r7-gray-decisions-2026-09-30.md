# F2 R7 灰区终裁建议

状态：2026-09-30 用户已回复“按整表推荐确认”，G1–G13 全表确认。本表建议不把预算或内存未达标混入视觉灰区；数值差距在
[R7 验证记录](renderer-r7-verification-2026-09-30.md)单列。原定义见
[上位方案 §8](../../plans/f2-renderer.md)，R6 D1–D7 与公共 API 不重开。

| 条 | 推荐终裁 | 复核与保留表述 |
|---|---|---|
| G1 | 保留四类黑盒面 | ①无背景文字底边近似/默认 font=0.8（官方未载默认值）；②端帽；③dash/dotted 节奏；④非基础 web 色。五原语、明载默认值、基础颜色及 alpha、背景 middle/padding 已实现，不能继续笼统称全部样式为黑盒；visuals 层位推断另标来源 |
| G2 | 按定义销账 | 真离屏 RT+MULTIPLY 的全局压暗已实现，双后端 real；历史“只有 ADD 亮斑”的缺口不存在。防御降级仍保留，迄今未实际触发，不写成验证过降级路径。normal/low/disabled 未全部实现与性能差距单独登记，不能以其重开 G2 |
| G3 | 继续挂账 M3 | 纯色圆为已选 v0 退化；徽标真实数据/自托管端点待账号与用户投影，本片不增范围 |
| G4 | 继续挂账真实输入 | renderer say/says、隐私与有限寿命已实现；合成通道不能证明引擎真实 say 事件已提供 |
| G5 | 分项保留缺口 | 已有真实六类事件与合成家族分开；远攻/群攻结算、lab/power/say/nuke 真实输入仍待引擎。PWR16–18 已有 SVG/图标；19+ 无映射计 skipped；flare3_all.hasEffect 尚无 renderer 实现，单列自身缺口，不能归咎引擎；lava=4 输入可接收、无独立视觉也单列 |
| G6 | 保留参数差异说明 | tickDurationMS 默认1000只定义动画时序，不驱动服务端 tick 或数据推送；倍率/进度与调用方职责已冻结，不把默认值称为实测官方 tick |
| G7 | 字体责任销账，采样微差保留 | 库内 FontFace 加载/失败回退/重试/释放与 stats 已完成；束端裁切、核弹四档 blur、确定性 flicker/初始角仍是构建期近似，字体抗锯齿不宣称逐像素跨平台一致 |
| G8 | 维持已销账 | 原白罩/mask 异常来自活 children 数组删除跳格；修复后官方层序工作，不复活错误观察 |
| G9 | 继续挂账 M3 users 映射 | 当前色板为官方 demo userOwnerColor 分支，本玩家 localPlayerId；用户远程颜色投影尚无，私有顶罩与公有 rampart 色板不混称 |
| G10 | 保真登记保留 | factory 两处 \|\| 优先级行为按官方现有实现复刻；不当作自有 bug 顺手改“正确”，上游变更后再随动 |
| G11 | 防御差异登记保留 | 未知 mineral 类型退 O/灰色；合法类型不受影响，非法输入路径比官方崩溃更稳，不能称官方保真 |
| G12 | 保真登记保留 | creep 白资源圆 when 按 \|\| 优先级实际行为复刻；不改成猜测的作者意图 |
| G13 | 自有辅助形态登记保留 | 白悬停环为交互辅助，命中政策与手势冻结已经 R6 确认；官方闭源信息卡属于客户端应用层，不能宣称环外观对齐官方 |

上述终裁只改变登记状态和措辞，不引入新视觉、低档光照、引擎改动或公共 API。
确认记录：2026-09-30 主会话异步决策，用户选择“按整表推荐确认”。正式性能差距仍待完整矩阵出数。
