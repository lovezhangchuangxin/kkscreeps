# D4 Mod 移动动作槽（2026-10-05）

本批基于 `a23c8d0`，继续贡献平面 D4：为 creep move 开放具名处理槽与受控移动请求能力，并把正常拒绝恢复扩展到移动请求登记。现行协议与限制见[移动动作槽](../../architecture/creep-move-slot.md)。

## 切点与实现

时序核查确认四个写入阶段：意图登记（`intent_move` 写 `old_fatigue` 与请求矩阵）、移动仲裁（消费矩阵与疲劳）、位移执行（道路磨损/工地踩踏/疲劳/索引）、跨房迁移（tick 级边缘标记 + 引擎阶段应用）。槽切点选在意图登记阶段：只开放请求登记的受控读写，不提供任意坐标写入或传送；实际位移与全部衍生效果仍由仲裁及执行阶段完成。

`Movement::add` 收紧为单执行者单请求不变量：入队前先移除本执行者既有登记。纯 native 路径每 tick 恰一条 move 意图、无既有登记可移除，行为不变（既有引擎测试全绿佐证）；移动槽内能力先登记时，后到的中心（native 或再次 request）覆盖先前登记，`pending()` 可在 wrap 内观察覆盖结果。请求与取消同步维护 `old_fatigue`，使疲劳仲裁（`can_move`）与评分沿用既有语义——漏记会使疲劳 creep 被误判可移动。

拒绝恢复按执行者粒度：引擎在整链开始前保存执行者的矩阵条目（目的格 + 格内登记序 + 原格）与 `old_fatigue`；拒绝时先移除本执行者现行登记、再按原登记序回插（序号越界钳到末尾）。恢复不触碰其他执行者的请求、`pull_of/pulled_by` 拉拽关系或矩阵其他格，因此不会撤销其他 creep 的有效请求；清空格移除键保持 `is_tile_busy`（spawn 方向选择消费）语义。

## 复审要点

- 能力预检与 native 意图共用同一静态障碍函数（提取 `has_static_obstacle`），含私有敌方 rampart；creep 冲突、疲劳、MOVE 部件检查留在仲裁/执行阶段，能力不能越过这些门槛。
- `pending()` 方向由登记目的格与执行者当前位置差值反推；意图阶段坐标不变，反推恒等于登记方向。
- 非法方向（0/9/小数/非数字）、失效 token、跨槽能力（移动槽用资源能力、资源槽用移动能力）经 op/SDK 双层校验记为故障，catch + decline 不能掩盖；处理器返回后能力关闭。
- 移动槽参数面固定为 `{ id, direction }`，不影响资源槽既有 `ctx.args` 键序；`ctx.movement` 与 `ctx.resources` 同为不可枚举属性。
- 资源能力未扩大到移动槽（无资源 journal），移动能力未扩大到资源槽（宿主门控）。
- 默认无 Mod 路径 Native 直调：不保存快照、不进 JS；无扩展时唯一的额外成本是 move 派发沿资源槽同形的 Rc 克隆。

## 验收矩阵

- JSON/KKPV 双通道：链序（before→wrap→中心→wrap 退栈→after）、权威参数刷新、wrap 内能力登记被 native 覆盖、replace 改向（BOTTOM 位移）与取消登记。
- before、wrap 前后、replace、after 五个位置正常拒绝：本执行者不动、竞争者照常入格、此前 drop 与后续 build（事件+进度）保留、双 Mod state 丢弃、整轮发布、无恢复门。
- 世界语义保持：抢格恰一胜者、对穿双成功、三 creep 环移、静止 creep/障碍结构阻挡、疲劳动一停一、无 MOVE 部件能力 request 亦不动、pull 随行免检、被拉者请求被拒时拉者照常移动。
- 道路磨损（ROAD_WEAROUT×身体数）与敌方工地踩踏仅在位移执行发生；拒绝后无磨损、无踩踏、无掉落、无 EVENT_EXIT 残留。
- 跨房：移上边缘格同 tick 过渡 + 源房 EVENT_EXIT；已在边缘格时移动请求被拒仍自动过渡（独立 tick 行为与拒绝显式区分）；向界外 request 返回 false 不登记不故障。
- 双玩家双房间：拒绝只作用于目标执行者；串行/并发派发世界快照一致；两玩家 Memory 照常发布。
- 晚期 RawMemory 写回失败：世界/玩家/Mod 状态不发布；重试传入抛错代码仍使用原玩家缓存，重建 realm 中重新结算并应用改向。
- 故障优先级：拒绝后异常、只读字段改写、重复 next、非法/过期能力均不可被 decline 掩盖，停用来源 Mod 后缓存轮重新结算。

- `KKSCREEPS_BIN="$PWD/target/release/kkscreeps" pnpm run check`：格式、Clippy、Rust、workspace JS、文档链接、源码规模检查全部通过；Rust 683 通过、0 失败、11 忽略，Mod 整链 75 通过，compat Node 14 通过。
- 完整 ratchet：2914 用例，1918 通过、89 失败、907 跳过，下限 1918；与开发前 `HEAD`、`HEAD~1` 逐条比较转红 0、转绿 0，无新增跳过或豁免。
- TooAngel/Overmind/WASM 各完成 2000/2000/10 tick，0 中断、0 惩罚跳过；Overmind 仅保留既有首 tick `DirectiveHarvest.create` 错误。固定世界 bot-check 不代表完整可玩性。

提交前复审未发现剩余阻断问题。本批不包含战斗/建造/容量动作槽、link tick 拒绝、跨房移动能力、寻路 wrapper 槽或持久化；`sim run` 场景不含 Mod 负载，零 Mod 开销沿用 C.5 登记待 D7 判读。
