# 真实 bot 场景执行入口（2026-10-04）

本批基于 `fdfb1d3`，在核心经济链完成后接入 `kkscreeps sim run`，将版本化 JSON 场景、玩家模块、初始 Memory、真实结算与最终状态断言连接为一个可复跑命令。开发始于 2026-10-04，最终门禁完成于 2026-10-05。现行格式和失败语义见[本地场景模拟](../../architecture/local-simulation.md)，实现见[sim.rs](../../../crates/kk-cli/src/sim.rs)。

## 覆盖范围

- 使用同一 EmbedEngine/ThreadExecutor，支持多玩家、JSON/KKPV 和并发配置；初始化不执行隐藏 tick。
- 经济夹具通过真实采集、搬运、升级、寿命到期与孵化替补验证持续推进。
- 失败测试覆盖异常、缺少 loop、CPU 硬中断、断言不成立、非法场景和输入文件保护。
- 宿主初始化测试覆盖初始 Memory、UTF-16 限额、待重试轮次拒绝替换模块/Memory，以及恢复后原模块继续执行。
- 精确整数断言覆盖超过 JS 安全整数范围的阈值，避免舍入误判通过。

不包含任意外部 bot 的完整玩法验收、Mod 场景、检查点、watch/replay 或确定性时钟。玩家异常可能提交当前轮次合法结果，与运行时契约一致。

## 验收记录

以下结果使用新鲜 `cargo build --release -p kk-cli` 产物，适配器显式 build，上游 pin 保持 `34a630efa42908c117c19c25d2350fa2387bd633`。门禁使用绝对 `KKSCREEPS_BIN` 指向本次 release。

```bash
target/release/kkscreeps sim run --scenario compat/fixtures/sim-economy/scenario.json --ticks 2000 --report docs/research/notes/sim-run-economy-json-2026-10-04.json
target/release/kkscreeps sim run --scenario compat/fixtures/sim-economy/scenario.json --ticks 2000 --kkpv --report docs/research/notes/sim-run-economy-kkpv-2026-10-04.json
KKSCREEPS_BIN="$PWD/target/release/kkscreeps" pnpm run check
KKSCREEPS_BIN="$PWD/target/release/kkscreeps" node compat/scripts/ratchet.mjs
```

两种通道均完成 2000/2000 tick，玩家错误与未求值轮次均为零，7 条断言全部通过。GCL 累计点数与控制器进度各增加 1468，Memory.loops 为 2000，实际孵化 4 个替补，初始两个 creep 已死亡。两份报告的最终世界与 Memory 完全一致，二进制指纹与当前 release 文件一致。原始报告：[JSON](sim-run-economy-json-2026-10-04.json)、[KKPV](sim-run-economy-kkpv-2026-10-04.json)。

推进循环墙钟分别为 257.59 ms 和 444.74 ms；同桌面并行运行门禁、没有预热，只作为本夹具的诊断记录，不构成正式通道性能比较或任意 bot 的性能保证。

`pnpm run check` 通过格式、workspace Clippy、629 个 Rust 测试（11 个忽略）、JavaScript workspace 测试（其中兼容适配器 14 个通过）和文档链接检查。Rust CLI 集成测试覆盖双通道 500 tick、多玩家、串/并行、失败退出与输入保护。

完整兼容性棘轮通过：1918 passed / 89 failed / 907 skipped，总数 2914，地板 1918 不变。相对当前 HEAD 逐用例零状态变化、零转红；脚本规定的 HEAD~1（D3）基线为 31 例转绿、零转红。两个既有豁免未命中本轮转红，脚本发出陈旧警告，未新增跳过或豁免。汇总见[机器记录](sim-run-2026-10-04.json)，全量结果见[套件报告](../../../compat/reports/kkscreeps.json)。
