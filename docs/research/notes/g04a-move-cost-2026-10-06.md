# G04.a 移动代价槽交付笔记（2026-10-06）

基线 `13c32c7`（登记提交随基线）。目标：开放移动域执行期的疲劳代价策略，补齐移动域最后一片决策点。

## 前置核对结论

执行链（`crates/kk-engine/src/settle/creep/movement.rs` `movement_execute`）：代价 = `move_weight`（非 MOVE/CARRY 件+负载，**裸值无下限**）× 地形费率（平原 2/沼泽 10/路 1 覆盖沼泽）；疲劳经 `add_fatigue` 转给 `head_puller` 链首拉者；恢复在 creep tick（-2×MOVE 件效能）；道路磨损（ROAD_WEAROUT×全身件数）、敌方工地踩踏、跨房入边缘疲劳归零为宿主固定顺序。

## 交付内容

1. **新槽 `builtin:room.moveCost`**（内建槽 19→20、revision v13、PlanHash 变更；SLOT_KEYS/描述符/bindings/install NATIVE/BUILTIN_SLOT_KEYS=20/freeze catalog 断言 20 全同步——G03.b 的坑本批未再漏）。`arbitrate_room` 末段（`finish_movement` 后、执行循环前）整房进 JS。
2. **能力面**：`ctx.cost.getFatigue`（缺省=原生代价）/`setFatigue(id, 0..=u32::MAX)` 数值替换，升/降双向；op 层 f64 收发 + 整数/值域校验（u32 在 JS 安全整数域内精确）。缺项/decline/故障回退原生；无幸存者不进 JS。
3. **引擎**：`Movement.costs` 覆盖表（瞬态，不进检查点）+ `cost_input` 投影（终局幸存者升序，`nativeFatigue` 与实收同源）+ `movement_execute` 消费覆盖；候选 `settle/move_cost.rs`。
4. **验收**：引擎 3（输入含原生要素/链首拉者、覆盖与缺项回退、域与值域）+ 运行时 7（沼泽原生停走 vs 策略续走对照、bog 平原隔 tick、decline、replace×after 组合 getFatigue 链、能力门、故障停用回退）+ swampwalker/bog 两独立包四场景 × 双通道 + 第 2 tick 后检查点冷恢复（sim 2 测试 97.4s）。
5. **文档**：architecture/mod-move-cost.md + 两索引 + 夹具 README + 本笔记。

## 本批坑

- **`nativeFatigue` 必须与实收同源**：投影初版用 `move_weight().max(1)`（预检/竞争输入的展示惯例），但 `movement_execute` 实收是裸 `move_weight`——纯 MOVE 件自重 0、原生代价 0，回退值虚高会被复审抓住（引擎测试钉死）。
- **停走者不进输入**：疲劳未清时玩家面 `move()` 预检拦截方向意图（G02.a 既知），停走 tick 无请求——mod_states 计数与"无幸存者不进 JS"的测试断言要按每 tick 实际移动者数算。
- **玩家代码先于结算**：sim 夹具里 Memory 记录的位置是结算前的，`--ticks 4` + `time>=3` 记录才等于 3 次落位后状态。
- **rustfmt 会重排链式调用的换行**（G03.b assemble 坑再现）：按块锚点编辑前先重读文件实际文本。
