# N2c 第三片：JS 群体伤害策略（2026-10-06）

基于 `18e8ea6`，开放同房战斗分页 `ctx.combat.list` 和 rangedMassAttack 槽中的 `applyDamageBatch`。作者使用独立 JS 筛选目标与计算每项伤害，宿主保护批量表示、延迟队列、死亡与统一发布。现行契约见[JS 群体伤害](../../architecture/mod-mass-policy.md)，机器证据见[验收数据](n2c-mass-policy-2026-10-06.json)。

## 实现与复审

- 分页按对象 ID 升序返回脱离副本，游标对象删除后仍能继续；列出有耐久表示的同房对象，包含执行者、孵化和零耐久对象，由 JS 决定资格。每页读取当前候选，不承诺修改期间的跨页快照一致性。
- 批量最多 256 项；SDK/op/引擎校验整数、非负与 1e9 上限，按实际 ID 检查重复，完整预检全部目标与队列表示域后再按输入顺序应用。直接引擎测试证明，非法末项不能先击毁前面的结构、登记事件或消耗 ID。
- SDK 复制有界数组条目；op 转换为可重入入口，转换期间不借用 OpState 或候选，之后复查能力、故障与 consumed。保留原始浮点校验，小数不截断；条目仅读取 id/amount，其他字段忽略。
- 批量与 native/request/cancel/单体伤害/治疗共用恰一次门。空批量也消耗动作并记录日志，没有攻击事件；before 成功应用后不追加原生群体伤害。
- 首触日志保存 JS 额外目标的原始对象与此前双队列。链内增删日志恢复被击毁结构、废墟、spawn 连带删除的孵化 creep、空间索引及 ID，局部拒绝保留此前伤害/治疗/转账与后续移动。
- 晚期 RawMemory 写回失败重建 realm 并复用玩家缓存，全部目标、Memory 和 namespace state 恰一次提交；没有新增检查点状态域。
- flat-mass 和 falloff-mass 分别使用固定 23 与 `ceil(40/(distance+1))`，两包完全使用公共 SDK，无包 ID 特殊分支。单选注册成功，双选报告多 replace 冲突。
- 文档复审修正选择性策略示例：rangedMassAttack 无 request 改向能力，保留默认中心可使用 wrap，在未选中执行者时调用 next。
