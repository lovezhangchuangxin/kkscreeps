# 里程碑执行方案

本目录存放**开发方案（plan）**：单个里程碑从设计到落地的执行文档——范围与验收、待确认的
关键决策、模块设计、任务与欠账清单、测试计划、提交切分序。方案是时效性文档：里程碑收口后
状态更新为已完成，只作历史留档。

与相邻目录的分工：

| 目录 | 体裁 | 寿命 |
|---|---|---|
| [plans/](.) | 开发方案：这个里程碑怎么干 | 时效性，收口即归档 |
| [../architecture/](../architecture/) | 技术架构：系统怎么构建 | 长期，随代码走 |
| [../designs/](../designs/) | 功能设计：玩家看到什么 | 长期，随代码走 |
| [../decisions/](../decisions/) | ADR：为什么这样决策 | 永久 |

方案中经确认的架构级结论，定型时升格为 ADR；实现现状回写架构文档（路线图"文档随代码走"纪律）。
